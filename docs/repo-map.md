# Repo map

| Path | What it is | You touch it when… |
|---|---|---|
| `apps/<p>/` | One project (`hello`, `echo`); layout in `docs/conventions.md` | building features |
| `apps/<p>/project.json` | Manifest: name, subdomain, db, `uses`, `exposes`, status, ports (schema `scripts/lib/projects.ts`) | renaming, linking projects, launching |
| `apps/<p>/infra/tables.json` | DynamoDB key schemas, read by seed and OpenTofu | changing a table |
| `packages/contracts/` | zod schemas (`src/<p>.ts`) and events (`src/events/`) | adding an endpoint or event |
| `packages/api-kit/` | Hono middlewares, `ddb()`, `publish()`, `onEvent()`, `createLambdaHandler`; `./local` for seed/tests | changing shared API behavior (redeploys every project) |
| `packages/web-kit/` | Typed client (`createApi`, `unwrap`, `InferResponseType`), UI basics | sharing web code |
| `templates/project/` | What `pnpm new` copies (`__NAME__` tokens; not linted directly) | changing what new projects get |
| `infra/bootstrap/` | State bucket, CI roles, `dr4w-boundary` — applied from the laptop only | changing CI permissions |
| `infra/platform/` | `dr4w-bus`, alerts, budget, optional Aurora — applied via `platform.yml` | shared infra |
| `infra/modules/` | The module catalog (`infra/modules/README.md`) | adding a kind of resource |
| `infra/backend.hcl` | Shared state settings (bucket, region, lockfile) | never (generated by bootstrap) |
| `scripts/` | `new-project`, `dev`, `seed`, `changed-projects`, `check-projects`, `ideas-status`, `doctor`, `docs-check`, `build-lambda`, `infra-check.sh`, `check-diagrams.sh` | changing a `pnpm` command |
| `ideas/` | One folder per idea (`00-idea.md`, `01-spec.md`, `02-tasks.md`) | using the idea pipeline |
| `.claude/commands/` | Slash commands: pipeline + session protocol | changing how Claude works here |
| `.github/workflows/` | `ci`, `deploy`, `platform`, `destroy`; `actions/setup` composite | changing CI/CD |
| `docs/` | All documentation — index: `docs/README.md` | — |
| `docker-compose.yml` | dynamodb-local (host 8100), Postgres (profile `pg`) | local services |
| `pnpm-workspace.yaml` | Workspace globs, **version catalog**, `allowBuilds` | adding/upgrading a dependency |
| `turbo.json`, `biome.json`, `tsconfig.base.json` | Task graph, lint/format, TS settings | tooling changes |
| `CLAUDE.md` | Agent entry point (loaded every session) | changing rules for Claude |
